# Second Brain v1 – report del 13 novembre 2026

Artifact privato (stesso indirizzo del prototipo): https://claude.ai/artifact/FixFdEmbd31YEYpuNbE4za
Sorgente: `app/index.html`. Capacità: `db`, `downloads` (il connettore `mcp` è stato tolto: dalla pagina non leggeva le sessioni).

## 1. Funzionalità implementate

| Area | Cosa fa |
|---|---|
| Stanze | Crea, modifica, archivia/riattiva, elimina (bloccata se ha memoria o collegamenti). Nome, descrizione, obiettivi, agenti assegnati. Contatori di memoria ed esecuzioni collegate |
| Agenti | Catalogo: nome, ruolo, istruzioni, strumenti, skill, accesso alla memoria. Etichetta "configurato" e frase esplicita che non indica lavoro in corso. Sezione separata "Esecuzioni reali collegate" |
| Skill | Crea, modifica, elimina (bloccata se usata). Assegnazione dalla scheda agente |
| Memoria | Contenuto, tipo (originale / riassunto / dedotto), fonte, data dell'informazione, stanza. Correzione con data di correzione, eliminazione in due tocchi, ricerca, filtri, segnalazione di possibili duplicati (stesso testo normalizzato), nessuna fusione automatica |
| Lavoro | Mostra l'istantanea salvata: data e ora, "non in tempo reale", età. Ogni stato è "rilevata: …" con l'età accanto; oltre 15 minuti diventa tratteggiato e, se era "in esecuzione" o "in attesa", compare "stato attuale non noto". Errore dell'ultimo aggiornamento mostrato sopra l'istantanea precedente |
| Collegamenti | Solo espliciti: per ogni sessione l'utente sceglie agente e/o stanza. Nessuna associazione per somiglianza di nome. Collegamenti a sessioni uscite dall'istantanea restano visibili a parte |
| Ricarica | "Ricarica istantanea salvata" rilegge l'archivio e lo dice; rimanda a «aggiorna stato» in Claude Code |
| Dati | Esporta tutto (6 collezioni) con impronta SHA-256; ripristino con verifica dell'impronta del file, riepilogo, conferma, sostituzione e verifica finale |
| «aggiorna stato» | `CLAUDE.md` + `strumenti/istantanea.mjs`: legge `list_sessions`, tiene solo id, titolo, stato, categoria, origine, date; scrive con `if_version`. In caso di errore aggiorna solo `ultimo_tentativo` |

## 2. Prove superate

| Prova | Evidenza |
|---|---|
| «aggiorna stato» reale | 2 rilevazioni (16:03 e 16:05 UTC), 9 sessioni ciascuna; seconda scrittura con `if_version` su documenti esistenti (istantanea v2, tentativo v3). Tra le due la sessione "TCL Minimal TV Fase 0" è passata da in esecuzione a in attesa: l'istantanea riflette il cambio |
| Riduzione dei dati | Con una risposta contenente riassunti (`task_summary`, `post_turn_summary`) l'istantanea non li contiene |
| Errore senza perdita di dati | Risposta non valida → lo script si ferma senza produrre l'istantanea; scritto solo `ultimo_tentativo` (esito errore); `istantanea` rimasta alla versione 1 |
| Freschezza | In browser con istantanea di 3 h: "Gli stati qui sotto descrivono quel momento, non adesso" e, per una sessione rilevata in esecuzione, "rilevata: in esecuzione · 3 h fa · stato attuale non noto" |
| Agente senza esecuzioni | Mostra "Nessuna esecuzione collegata. Questo agente non risulta al lavoro." |
| Esporta / ripristina | In browser con i dati reali dell'archivio: esportazione con impronta `03878a2b…`, identica a quella calcolata in Node sugli stessi dati; dopo aver alterato un elemento e aggiunto una skill, il ripristino ha riportato l'impronta identica |
| Layout telefono | 390 px: nessuno scorrimento orizzontale, nessun errore in console |

Le prove in browser usano un archivio simulato in memoria con i dati letti dall'archivio vero: verificano la logica della pagina, non la piattaforma.

## 3. Limiti ancora aperti

| Limite | Effetto |
|---|---|
| Nessun collegamento in tempo reale | La pagina non può leggere le sessioni (`blocked_by_policy`); lo stato è aggiornato solo quando chiedi «aggiorna stato» |
| Prova della v1 dal telefono | Non verificato: creazione/modifica, collegamenti, esportazione e ripristino vanno provati sull'app Android |
| Aggiornamento automatico | Nessuna attività pianificata attivata; non verificato se una sessione pianificata possa scrivere nell'archivio |
| Elenco sessioni | Al massimo 50 per aggiornamento (le più recenti); oltre è segnato "troncato" |
| «aggiorna stato» fuori da questo repository | Le istruzioni sono in `CLAUDE.md`: funzionano in una sessione aperta su questo repository |
| Avvio di agenti dalla pagina | Non disponibile (la pagina non può creare sessioni) |
| Duplicati | Solo testo identico dopo normalizzazione; nessuna somiglianza semantica |
| Importazione chat di Claude | Non ancora implementata (file di esportazione dal web/desktop) |
| Documenti e attività nelle stanze | Non ancora implementati |
| Dimensione archivio | 25.000 documenti; tetto di dimensione totale non pubblicato |
| Costi | I valori in dollari che compaiono nei dati delle sessioni sono stime equivalenti a listino, non addebiti verificati |
| Dati di prova | Agenti, skill, stanze, memoria marcati "(fittizio)" e il collegamento `co-prova-sviluppatore` sono di prova: da eliminare quando inizi a usare dati reali |
