Sincronizzazione

Cosa resta sul telefono e cosa va su GitHub Stanze, agenti, skill, collegamenti e le memorie che rendi accessibili agli agenti vengono copiati nel repository privato second-brain (ramo «dati»). Le altre memorie restano solo sul telefono e nelle esportazioni. Eliminare un dato dall'app lo toglie dalla versione attuale del repository alla sincronizzazione successiva, ma non lo cancella dalla cronologia Git: le versioni precedenti restano consultabili nel repository.

Conflitti da risolvere

Lo stesso dato è stato modificato sia sul telefono sia nel repository. Nessuna delle due versioni è stata sovrascritta: scegli quale tenere.

Accesso GitHub

  1. Tocca Apri GitHub: si apre la pagina per creare un token a grana fine (accedi se richiesto).
  2. Token name: «Second Brain telefono». Expiration: 90 giorni (o la scadenza che preferisci).
  3. Resource owner: il tuo account. Repository access: Only select repositories → second-brain.
  4. Permissions → Repository permissions → Contents: Read and write. Nient'altro (Metadata in sola lettura viene aggiunto da GitHub).
  5. Tocca Generate token, copia il token (inizia con github_pat_) e incollalo qui sotto.

Il token viene cifrato con una chiave del telefono (Android Keystore) e non compare mai nell'app, nelle esportazioni o nei registri. Per revocarlo: GitHub › Settings › Developer settings › Fine-grained tokens.

Esportazione

Salva un file JSON con tutti i dati (anche le memorie private) e la loro impronta SHA-256. Il token non è mai incluso.

Ripristino e migrazione

Scegli un backup di Second Brain (anche quello della versione web). L'impronta viene verificata prima di cambiare qualsiasi cosa.
